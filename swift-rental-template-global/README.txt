SWIFT RENTAL — GLOBAL TEMPLATE
================================================================

A framework-free, single-file car rental website template. English-first,
with a bonus Indonesian version. Opens by double-clicking index.html —
no Node.js, no build tools, no external database, no APIs.

WHAT'S IN THE BOX
----------------------------------------------------------------
01-WEBSITE-EN/           Primary product: English version.
02-WEBSITE-ID/           Bonus: Indonesian localization (same design).
03-DOCUMENTATION/        Setup, customization, and SEO guides.
04-LICENSE/              License file.
CHANGELOG.txt            Version history.

HOW TO OPEN
----------------------------------------------------------------
Double-click index.html inside either 01-WEBSITE-EN or 02-WEBSITE-ID.
For a local dev server (optional), any static file server works, e.g.:
  python3 -m http.server 8080

READ FIRST
----------------------------------------------------------------
Open 03-DOCUMENTATION/GETTING_STARTED.md before publishing —
it lists every placeholder that must be replaced (brand name,
domain, phone, email, address, coordinates, opening hours, prices,
social profiles, and the social-sharing image).

IMPORTANT DISCLOSURE
----------------------------------------------------------------
All demo content is fictional. The template must not be published
with placeholder credentials, addresses, phone numbers, testimonials,
or bank details. Replace them with your own verified information first.
See 03-DOCUMENTATION/CUSTOMIZATION.md for the full checklist.

SUPPORT
----------------------------------------------------------------
Support covers questions about using the template as delivered.
It does not cover custom development, hosting, domain setup,
third-party integrations, or content writing beyond the demo copy.
